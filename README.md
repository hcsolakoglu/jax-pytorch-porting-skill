# JAX and PyTorch Model Porting

An evidence-driven agent skill for bidirectional JAX and PyTorch model ports, including inference, training, checkpoint conversion, numerical validation, and performance measurement.

Development status: research and validation in progress. No production, accelerator, or speed claim is implied by repository creation.

Research contract and scoring rules are in `research/CONTRACT.md` and `research/rubric.md`. Development will keep external evidence, designed procedures, direct experimental observations, and untested areas separate.
